# Backend Services & Transport Layer

Этот репозиторий содержит мою часть работы над бэкендом (написанном на Go) в рамках группового проекта. В данном проекте я отвечал за проектирование и реализацию пользовательского сервиса, разработку транспортного REST-слоя, глобальный рефакторинг архитектуры и настройку CI/CD пайплайнов для деплоя.

## 🚀 Мои задачи и достижения в проекте

### 1. Сервис пользователей (`internal/user`)
- Разработана логика автоматической генерации и управления анонимными профилями пользователей.
- Реализована надежная привязка игровых сессий к сгенерированным идентификаторам пользователей.
- Настроен слой абстракций (Storage Interface) для взаимодействия с базой данных PostgreSQL для масштабирования профилей.

### 2. Транспортный слой и API (`internal/transport`)
- Спроектирован и написан REST API (маршрутизаторы, хендлеры) для общения между клиентской частью и ядром бэкенда.
- Настроены политики CORS для безопасного взаимодействия микросервисов.
- Реализована обработка ошибок и валидация входящих JSON-запросов от клиента.
- Интегрированы Middleware для перехвата и логирования запросов.

### 3. Рефакторинг и Архитектура
- Проведен глобальный рефакторинг кодовой базы с переходом на принципы Clean Architecture (разделение на слои: Domain, Usecase, Adapter, Transport).
- Вычищен легаси-код, улучшена читаемость и поддерживаемость кодовой базы.
- Устранены баги в логике парсинга параметров при вызове сторонних API.

### 4. Деплой и Инфраструктура
- Написан оптимизированный `Dockerfile` для сборки Go-бэкенда.
- Настроены GitHub Actions для автоматической сборки (CI).
- Реализован автоматический деплой базы данных (PostgreSQL), in-memory кеша (Redis) и самого Go-приложения в облачной платформе Railway.

## 🛠 Технологии
- **Язык программирования:** Go (Golang)
- **Базы данных:** PostgreSQL, Redis
- **Архитектура:** REST API, Clean Architecture
- **Инфраструктура:** Docker, GitHub Actions, Railway, Nginx

## 📁 Структура репозитория
- `/internal/user/` — Исходный код бизнес-логики управления пользователями.
- `/internal/transport/` — Исходный код HTTP-сервера, роутеров и обработчиков API.
